# Linux / Unix 数据布局与分级参考

Linux 和其他 Unix-like 系统的扫描结果进入与 macOS、Windows 相同的快照 JSON 和 HTML 报告。平台适配器只负责读取目录与文件系统信息，分析和可视化逻辑保持共用。

- `$HOME`：当前用户文件、Downloads、`.config`、`.local/share` 和开发缓存。
- `$HOME/.cache`：通常可再生，但仍需确认正在运行的应用不会依赖当前缓存。
- `/home`：本机用户目录；其他用户如果因权限无法读取，必须在报告中标记为未完整统计。
- `/var/cache`、`/tmp`：系统或临时缓存，默认不提供后台删除按钮。
- `/proc`、`/sys`、`/dev`、`/run`：虚拟或运行时文件系统，不计入普通根目录空间排行。

打开位置使用 `xdg-open`；移入回收站遵循 XDG Trash 规范。没有桌面环境或回收站实现时，报告仍可作为只读 HTML 使用，清理按钮保持不可用。

权限不足时应使用目标文件所属账号运行并检查所有权或 ACL；不要用 `sudo` 启动本地报告服务。权限只决定可读取的统计范围，清理仍限制在当前用户 HOME 内的本次已验证精确路径。
